## 기호표 {#cheatsheet}

참은 1, 거짓은 0으로 씁니다.

### 논리: 조건을 조합하기

| 기호 | 이름 | 뜻 |
|---|---|---|
| $A \land B$ | AND, 그리고 | 둘 다 참일 때만 참입니다. 1∧0 = 0 |
| $A \lor B$ | OR, 또는 | 하나라도 참이면 참입니다. 1∨1도 1 |
| $A \oplus B$ | XOR, 배타적 또는 | 둘의 값이 다를 때만 참입니다. 1⊕1 = 0 |
| $\lnot A$ | NOT, 부정 | 참과 거짓을 뒤집습니다. ¬1 = 0 |
| $\lnot(A \land B)$ | NAND | 둘 다 참인 경우만 거짓입니다 |
| $\lnot(A \lor B)$ | NOR | 둘 다 거짓일 때만 참입니다 |
| $A \Rightarrow B$ | 함의, ~이면 | A는 참인데 B가 거짓인 경우만 거짓입니다 |
| $\lnot(A \land B) = \lnot A \lor \lnot B$ | 드모르간 법칙 | 괄호 전체의 부정을 안으로 옮기면 AND와 OR가 바뀝니다 |

::: {.note}
논리 연산은 참·거짓을 다루고, 비트 연산은 정수의 각 자리에 같은 규칙을 적용합니다. 코드에서 쓰는 실제 기호(`&&`, `&`, `|`, `^`)와 계산 순서는 언어마다 다르니 확인하세요.
:::

### 집합: 범위와 대상을 묶기

| 기호 | 이름 | 뜻 |
|---|---|---|
| $x \in A$ | 원소 | x가 A에 속합니다. 2 ∈ {1, 2, 3} |
| $A \cup B$ | 합집합 | 두 집합에 있는 것을 중복 없이 모읍니다 |
| $A \cap B$ | 교집합 | 두 집합에 공통으로 있는 것만 남깁니다 |
| $A \setminus B$ | 차집합 | A에서 B에도 있는 것을 뺍니다 |
| $A \subseteq B$ | 부분집합 | A의 모든 원소가 B에도 있습니다 |
| $\emptyset$ | 공집합 | 원소가 하나도 없는 집합입니다. 숫자 0과는 다릅니다 |
| $[a, b)$ | 반열린 구간 | a는 포함하고 b는 제외합니다. [0, 3)은 0 ≤ x < 3 |
| $\forall$ / $\exists$ | 모두 / 하나 이상 | ∀는 전부 만족, ∃는 만족하는 것이 하나 이상 있다는 뜻입니다 |

### 계산: 식을 읽는 기본 도구

| 기호 | 이름 | 뜻 |
|---|---|---|
| $2^3 = 2 \times 2 \times 2$ | 거듭제곱 | 같은 수를 반복해서 곱합니다. 2³과 2×3은 다릅니다 |
| $\log_2 8 = 3$ | 로그 | "2를 몇 번 곱해야 8이 되는가"입니다. 거듭제곱을 거꾸로 읽습니다 |
| $\lvert -3 \rvert = 3$ | 절댓값 | 0까지의 거리입니다. 부호를 뗀 크기 |
| $\lfloor 2.7 \rfloor = 2$, $\lceil 2.1 \rceil = 3$ | 내림, 올림 | 내림은 그 수 이하의 가장 큰 정수, 올림은 그 수 이상의 가장 작은 정수입니다 |
| $7 \bmod 3 = 1$ | 나머지 | 3개씩 묶고 남은 수입니다. 음수일 때의 규칙은 언어마다 다릅니다 |
| $f(x) = 2x + 1$ | 함수 | 입력에서 출력을 정하는 규칙입니다. x = 3을 넣으면 7 |
| $g(f(x))$ | 함수 합성 | f를 먼저 계산하고 그 결과를 g에 넣습니다 |
| $\sum x_i = x_1 + x_2 + \cdots$ | 합 기호 | 여러 항을 모두 더합니다. i는 항의 번호입니다 |

### 좌표·비율·확률

| 기호 | 이름 | 뜻 |
|---|---|---|
| $(x, y)$ | 좌표 | 원점과 두 축을 정한 뒤 위치를 숫자 두 개로 적습니다 |
| $(x + \Delta x,\; y + \Delta y)$ | 이동 후 좌표 | Δ(델타)는 변화량입니다. 지금 좌표에 이동량을 더합니다 |
| $d^2 = (\Delta x)^2 + (\Delta y)^2$ | 거리의 제곱 | 가로 차이와 세로 차이를 각각 제곱해 더합니다 |
| 부분 ÷ 전체 | 비율, 퍼센트 | 3/12 = 0.25 = 25%. 무엇을 전체(분모)로 잡았는지 봅니다 |
| 합 ÷ 개수 | 평균 | [2, 4, 9]의 평균은 15/3 = 5 |
| $0 \le P(A) \le 1$ | 확률 | 사건 A가 일어날 가능성을 0에서 1 사이로 나타냅니다. 0.25는 25% |
| $P(\lnot A) = 1 - P(A)$ | 일어나지 않을 확률 | 성공 확률이 0.8이면 실패 확률은 0.2입니다 |
| $P(A \cap B) = P(A)\,P(B \mid A)$ | 둘 다 일어날 확률 | A의 비율에, A인 것들 안에서 B의 비율을 곱합니다 |
