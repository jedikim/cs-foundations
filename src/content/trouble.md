## 어떤 문제든 먼저 할 일 {#first}

1. **오류 글을 끝까지 읽습니다.** 맨 아랫줄에 무슨 오류인지가, 그 위에 어느 파일 몇째 줄인지가 적혀 있습니다. → [초코딩 기초](code.html#error), [12장](ch12.html#trace)
2. **방금 무엇을 바꿨는지 봅니다.** 조금 전까지 됐다면 원인은 그 뒤에 바뀐 것 안에 있습니다. → [7장](ch07.html#diff)
3. **같은 문제를 다시 일으켜 봅니다.** 무엇을 누르면 생기는지 순서를 적습니다. → [12장](ch12.html#repro)
4. **AI에게는 세 가지를 함께 줍니다.** 오류 글 전체, 내가 한 순서, 기대한 것과 실제로 일어난 것. "안 돼"만 주면 AI는 짐작으로 고칩니다. → [30장](ch30.html#stuck)

## 요청이 실패할 때 {#request}

| 이런 일이 생기면 | 먼저 볼 것 | 읽을 곳 |
|---|---|---|
| 상태 코드 `400`, `422` | 보낸 값의 이름과 모양이 서버가 바라는 것과 같은가 | [15장](ch15.html#message), [18장](ch18.html#contract) |
| `401`, `403` | 로그인이 풀리지 않았는가. 그 일을 할 권한이 있는가 | [19장](ch19.html#authn), [19장](ch19.html#authz) |
| `404` | 주소의 철자. 그 주소를 받는 코드가 서버에 있는가 | [15장](ch15.html#message) |
| `429` | 너무 자주 불렀는가. 한도가 얼마인가 | [13장](ch13.html#limits), [19장](ch19.html#authz) |
| `500` | 서버의 로그에 찍힌 오류 글 | [22장](ch22.html#log), [12장](ch12.html#trace) |
| `502`, `504` | 뒤에 있는 서버가 꺼졌거나 너무 오래 걸리지 않는가 | [15장](ch15.html#message), [18장](ch18.html#remote) |
| Console에 CORS 오류 | 서버가 내 화면의 주소를 허락하고 있는가. 화면 쪽에서는 못 풉니다 | [15장](ch15.html#cors) |
| 연결을 거부당한다(`Connection refused`) | 서버가 켜져 있는가. 포트 번호가 맞는가 | [14장](ch14.html#localhost), [14장](ch14.html#transport) |
| 한참 기다리다 실패한다(timeout) | 서버가 느린가, 가는 길이 막혔는가 | [14장](ch14.html#speed), [18장](ch18.html#retry) |
| 주소를 찾지 못한다 | 도메인 이름의 철자. 방금 연결한 도메인이라면 조금 기다립니다 | [14장](ch14.html#dns) |
| 내 컴퓨터에서는 열리는데 친구는 못 연다 | 주소가 `localhost`가 아닌가. 그 주소는 내 컴퓨터만 가리킵니다 | [14장](ch14.html#localhost), [31장](ch31.html#deploy) |

## 데이터가 이상할 때 {#data}

| 이런 일이 생기면 | 먼저 볼 것 | 읽을 곳 |
|---|---|---|
| 저장했는데 새로 고치면 사라진다 | 메모리에만 두지 않았는가. 데이터베이스까지 갔는가 | [1장](ch01.html#storage), [17장](ch17.html#why) |
| 같은 것이 두 번 저장된다 | 버튼이 두 번 눌리지 않았는가. 실패한 줄 알고 다시 보내지 않았는가 | [15장](ch15.html#retry), [18장](ch18.html#retry) |
| 두 사람이 동시에 하면 값이 틀어진다 | 읽고 나서 고치는 사이에 남이 끼어들 수 있는가 | [11장](ch11.html#race), [17장](ch17.html#concurrency) |
| `undefined`, `None`, `null` 때문에 오류가 난다 | 값이 비어 있을 때를 코드가 다루고 있는가 | [8장](ch08.html#empty) |
| 돈이나 점수 계산이 조금 어긋난다 | 소수로 계산하고 있지 않은가 | [2장](ch02.html#float) |
| 시각이 몇 시간씩 어긋난다 | 시간대를 붙여 저장했는가 | [8장](ch08.html#exchange) |
| 자료가 늘수록 느려진다 | 전부 가져와서 하나씩 뒤지고 있지 않은가 | [9장](ch09.html#nested), [17장](ch17.html#index) |
| 남의 자료가 보인다 | 누구 것인지를 화면이 아니라 서버가 확인하는가 | [19장](ch19.html#authz), [31장](ch31.html#data) |
| 올린 사진이나 파일이 사라진다 | 파일을 어디에 저장하고 있는가. 서버를 새로 올려도 남는 곳인가 | [16장](ch16.html#upload), [21장](ch21.html#disposable) |
| 표 구조를 바꿨더니 오류가 난다 | 이미 들어 있는 자료는 어떻게 되는가. 바꾸기 전에 백업했는가 | [17장](ch17.html#operate) |
